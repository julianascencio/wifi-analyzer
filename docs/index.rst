Wi-Fi Analyzer
===================

**ASVA Consulting — received-power surveys, reproducible analysis and maps.**

A practical collection of acquisition tools, methods and runnable examples,
following the modular library and evidence-led gallery approach of OrbitalPV.
Start with the synthetic 50 m property demo, then collect real observations
with the Android app and feed them through the same analysis pipeline.
